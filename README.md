# 위험성평가 도우미 래온 (v2.0)

공동주택 관리사무소장을 위한 **위험성평가 따라하기 웹앱**입니다. 설치 없이 크롬·휴대폰 브라우저에서 바로 씁니다.

- 앱 주소: https://kthightech-rgb.github.io/raeon-risk/
- 근거: 산업안전보건법 제36조, 같은 법 시행규칙 제37조~제37조의4, 사업장 위험성평가에 관한 지침(고용노동부고시 제2026-73호)
- 법령 기준일: 2026.11.15.

## 할 수 있는 일
1. 단지 정보 자동 조회 (K-apt · 공공데이터포털 인증키 필요, 선택)
2. 법령·고시 개정 실시간 확인 (국가법령정보 OC 필요, 선택)
3. 휴대폰으로 현장 순회점검 · 상·중·하 판정 · 사진
4. 실시규정(Word), 위험성평가표(Excel 10개 시트) 자동 작성
5. 관련 포탈(산업안전포털 KRAS, MSDS, 고용노동부 등) 단계별 확인

## 개인정보
입력한 내용·사진·인증키는 사용하는 기기의 브라우저에만 저장되며, 이 앱은 서버로 아무것도 보내지 않습니다.

## 주의
산출물은 작성 보조용입니다. "참고등급"은 예시이므로 반드시 근로자와 함께 현장에서 판정하고, 최종 내용은 사업주·관리사무소장이 확인하세요.

## 이용 안내

- 이 앱은 래온(來On)이 만든 무료 도구이며, 국토교통부·K-apt·중앙공동주택관리지원센터·주택관리사협회의 공식 서비스가 아닙니다.
- 결과물은 작성 보조용 참고자료입니다. 법령 적용과 최종 내용의 확인·책임은 사용하는 관리주체에게 있습니다.
- 입력한 내용·파일·인증키는 이 브라우저에만 저장되며 제작자에게 전송되지 않습니다. 접속 기록은 호스팅하는 GitHub에 남을 수 있습니다.
